# Échos des siècles

- **Site boutique** : `index.html` + `img/`, publié sur echosdessiecles.fr à chaque push sur `main`.
- **Admin** : `admin/`, sur echosdessiecles.fr/admin (démo : `/admin/?demo`).
- **Moteur** : `engine/` (veille Interenchères, bot Telegram, publication site / eBay / Leboncoin),
  lancé toutes les 5 minutes par GitHub Actions. Données privées chiffrées dans `data/`.

Mise en route, coûts et fonctionnement : [docs/ADMIN.md](docs/ADMIN.md).
